2. EXECUTABLE PRICE DEFINITION
Executable price is not spot price.
Executable price means:
{
  executable_price: "actual effective price after fees, slippage, liquidity 
depth, and exact input amount"
}
It is calculated from executable quote output:
{
  LEG1_executable_price = amountIn_A / amountOut_B,
  LEG2_executable_price = amountOut_A / amountIn_B
}

Where:
{
  amountIn_A: "starting asset input",
  amountOut_B: "intermediate token output from LEG1",
  amountIn_B: "intermediate token input to LEG2",
  amountOut_A: "starting asset output from LEG2"
}

5. EXECUTABLE SPREAD
Once LEG1 and LEG2 are normalized into the same quote unit:
{
  executable_spread = LEG2_executable_price - LEG1_executable_price
}
Example:
{
  LEG1_buy_price: 1.6000,
  LEG2_sell_price: 1.6192,
  executable_spread:
    "1.6192 - 1.6000 = 0.0192 USDC per WMATIC"
}
Spread percentage:
{
  executable_spread_pct =
    ((LEG2_executable_price - LEG1_executable_price)
    / LEG1_executable_price) * 100
}
Example:
{
  executable_spread_pct:
    "(0.0192 / 1.6000) * 100 = 1.20%"
}
Dashboard label:
EXECUTABLE SPREAD:
+0.0192 USDC / WMATIC
+1.20%

6. GROSS PROFIT FROM LEG1 / LEG2
The route-level gross profit is not the spread alone.
It is:
{
  gross_profit_A = final_amount_A - initial_amount_A
}
Example:
{
  initial_USDC: 100000,
  final_USDC: 101200,
  gross_profit_USDC:
    "101200 - 100000 = 1200 USDC"
}
Dashboard label:
GROSS PROFIT:
+1,200 USDC
7. NET PROFIT FROM LEG1 / LEG2
Net profit includes execution costs.
{
  net_profit_A =
      final_amount_A
    - initial_amount_A
    - flash_fee_A
    - gas_cost_A
    - priority_fee_A
    - relay_or_bribe_A
    - slippage_buffer_A
    - state_drift_buffer_A

}
